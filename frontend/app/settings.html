🛡️ Data Sovereignty & Shopkeeper Security Guarantees

  • Zero Permanent Audio Storage: Voice turns are processed in volatile memory. Raw audio files are discarded immediately after transcription.
  • Local Ledger Sovereignty: Customer balances, debt transactions, and medical reminders are stored in local SQLite without external cloud replication.
  • Deterministic Fallback: In no-internet environments or when API credentials are absent, rule-based natural language parsers handle all standard Hindi, Marathi, and English commands.
  • Credential Safety: API tokens are stored server-side in .env and masked in all diagnostic outputs. Zero secrets are transmitted to the browser.
